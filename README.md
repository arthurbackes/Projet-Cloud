# LINFO2145 Repository

Private repository for the students of LINFO2145 (Cloud Computing) of the class 2026-2027. Students should create a **private fork** of this repository and pull instructions when they are made available.

## Structure

- **slides** : Directory where copies of the slides used during the course are available in case you don't have access to Moodle yet;
- **tutorials** : Directory containing instructions for the tutorial;
- **project** : Directory containing the source code and instructions for the project.
